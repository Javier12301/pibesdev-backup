Herramienta interna · Google Drive API

Copias de seguridad cifradas para la infraestructura de PibesDev.

PibesDev Backups es una integración privada que utiliza Rclone y Google Drive para almacenar y recuperar respaldos de nuestros servidores. No es un servicio público ni permite registrar usuarios.

Cómo funciona

1 · Generación

El servidor genera respaldos de bases PostgreSQL y archivos persistentes de las aplicaciones administradas por el equipo.

2 · Cifrado

El flujo de backup está diseñado para cifrar los archivos antes de subirlos mediante Rclone Crypt. Su puesta en producción depende de verificar el cifrado y la restauración.

3 · Almacenamiento

Una cuenta de Google expresamente autorizada permite crear y administrar únicamente los archivos y carpetas accesibles para esta integración mediante el permiso drive.file.

Acceso limitado a Drive

Solicitamos el permiso https://www.googleapis.com/auth/drive.file para crear, consultar, actualizar y recuperar las copias que administra Rclone. No solicitamos acceso general a los demás archivos de Google Drive.

La aplicación se utiliza únicamente por sus administradores para mantener los respaldos de infraestructura. No ofrece acceso a terceros a través de esta página.
